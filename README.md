# Скрипт на Python для определения температуры городов

Скрипт берет значения городов из Cities.txt и выводит данные в output.txt. Данные о погоде берутся из API [wttr.in](https://wttr.in). Для каждого города выводятся страна и температура, затем города группируются по странам: количество городов, средняя, минимальная и максимальная температура.

Скрипт нужно запускать из папки проекта: рядом с weather.py должен лежать Cities.txt, и туда же будет записан output.txt.
